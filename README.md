# QA Testing Portfolio

My own collection of software testing documentation and automated tests demonstrating my approach to software quality assurance, functional validation, reporting, and regression testing.

## Overview

This doc showcases practical QA skills developed alongside my background in full-stack software engineering. It focuses on validating application functionality, documenting test results, identifying defects, and verifying that software behaves as expected.

## Skills & Tools

- **Test Automation:** Playwright, JavaScript
- **Testing:** Functional Testing, Regression Testing, Exploratory Testing
- **Defect Reporting:** Reproduction Steps, Expected vs. Actual Results, Severity and Priority
- **QA Documentation:** Test Plans, Test Cases, Test Execution Results
- **Development:** REST APIs, Web Applications, Debugging

## Repository Contents

- **Test Plan:** Defines testing scope, objectives, assumptions, and approach.
- **Test Cases:** Documents test scenarios, steps, expected results, and execution status.
- **Automated Tests:** Playwright scripts validating key application workflows.
- **Defect Reports:** Documents issues with reproduction steps, expected and actual behavior, and severity.
- **Test Results:** Summarizes execution outcomes, failures, and regression coverage.

## Testing Approach

My testing process focuses on:

1. Reviewing application requirements and identifying important user workflows. Communication with other teams.
2. Developing test cases with clear steps and expected outcomes.
3. Executing functional tests and recording results.
4. Investigating unexpected behavior and documenting reproducible defects.
5. Retesting fixes and running regression tests to check for unintended side effects.
6. Maintaining clear documentation of test coverage and outstanding issues.
